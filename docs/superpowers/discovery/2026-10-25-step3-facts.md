### D.6 Listing fields written by other people (must never reach the model)
`routers/listings.py:141-142, 189-192` and `listings.py:133-135, 238-258`:
- `title`: free text, 80 chars for sellers; for shop listings it is the **shop website's** text (`raw.title`).
- `city` (40), `contact` (60), `size` (20): seller-typed. `review_note`: written by an admin.
- `brand`, `shop_colour`, `url`, `price_original`: copied from shop sites.
- **What the old code sends today:** `short_listing` (`shopping.py:17-31`) drops `contact` and `review_note` but **does send `title`, `brand`/`shop_name`, `shop_colour` and the seller's `city`**; `my_listings` (`seller.py:59`) sends `title` and **`review_note`**; `price_hint` examples (`resale.py:68`) send `title`. So untrusted text does reach the model in the old design.
- Other free text the user wrote themselves: profile `name`, `wear_log.event_name`, chat messages. Item labels are model predictions or the user's picks from fixed lists, not free text.
- Not checked: the text fields of the H&M catalogue (`Catalog.search_shop` rows).
